# 关卡文本格式（Level Format）

关卡文件是纯文本，扩展名建议用 `.txt`。编码使用 UTF-8。

## 整体结构

```text
name: 关卡名
author: 作者（可选）
hint: 提示（可选）

[floor]
########
#......#
#..O...#
########

[boxes]
........
...K....
........
```

- 以 `//` 开头的行是注释，解析时忽略。
  **注意**：不要用 `#` 当注释——`#` 在 `[floor]` 里表示虚空。
- 以 `[xxx]` 开头的行是区块标记，目前只支持 `[floor]` 和 `[boxes]`。
- 区块外（即第一个区块之前）的 `key: value` 行是元数据，支持的 key：
  `name`（必填，缺省为「未命名关卡」）、`author`（可选）、`hint`（可选）。
- 元数据必须出现在第一个 `[xxx]` 区块之前。

## [floor] 图例（地面层）

| 字符 | 含义 |
| ---- | ---- |
| `.`  | 地砖（可通行、可放箱子） |
| `O`  | 钥匙孔（目标格） |
| `#`  | 虚空（不可通行、不可放箱子） |

## [boxes] 图例（箱子层）

| 字符 | 含义 |
| ---- | ---- |
| `.`  | 空 |
| `B`  | 白板箱（纯障碍，只能被别的箱子推/拉） |
| `K`  | 钥匙箱（目标物） |
| `F`  | 固定箱（完全不能移动） |
| `^`  | 方向箱（向上） |
| `v`  | 方向箱（向下） |
| `<`  | 方向箱（向左） |
| `>`  | 方向箱（向右） |

## 校验规则

- `[floor]` 与 `[boxes]` 行数必须一致。
- 每一行的长度必须一致（两层之间、以及层内各行之间）。
- `[boxes]` 中有箱子的格子，`[floor]` 对应位置不能是虚空 `#`。
- 任一字符不在上述图例中都会报错。
