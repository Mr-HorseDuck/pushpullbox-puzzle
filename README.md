# 推拉箱谜题（Push-Pull Puzzle）

一个纯前端的推箱子变体小游戏。**双击 `index.html` 即可直接游玩**，无需任何服务器、构建工具或第三方依赖。

## 玩法

- 棋盘由三种地面组成：**地砖**、**钥匙孔**、**虚空**。
- 箱子有四种：
  - **白板箱**：纯障碍，只能被别的箱子推/拉。
  - **固定箱**：完全不可移动，推/拉遇到它只会跳过该侧。
  - **钥匙箱**：目标物。
  - **方向箱**：玩家可点击，分上/右/下/左四向。
- 点击方向箱时：
  - **推**：沿箭头方向扫描，把第一只箱子朝远离方向箱的方向推一格。
  - **拉**：沿反方向扫描，把第一只箱子朝方向箱拉近一格。
  - 方向箱自己永远不移动；推与拉独立结算，一侧失败不影响另一侧。
  - 推拉都没有任何变化时，本次点击无效（不计步、不入历史）。
- 所有**钥匙箱**都位于**钥匙孔**上即通关。

## 操作

- 游戏界面：点击方向箱移动箱子。
- 底部按钮：撤回 / 重做 / 重开。
- 键盘：`←` 撤回 · `→` 重做 · `空格` 重开。

## 界面

- **主菜单**：开始游戏 / 打开关卡文件夹 / 导入关卡 / 关卡编辑器 / 规则说明，以及「内置关卡」「本地文件夹」「我的关卡」三个列表。
- **游戏界面**：自适应尺寸的 CSS Grid 棋盘、步数、通关横幅。
- **关卡编辑器**：调色板绘制（左键画 / 右键擦箱子）、调整宽高、填写关卡信息，并支持打开本地关卡、直接保存回本地文件（Ctrl+S）、另存为本地文件、导入/导出 TXT、试玩。
- **导入界面**：粘贴关卡文本或读取 `.txt` 文件后直接开始。

## 如何打开本地关卡文件夹

1. 在浏览器（推荐 Chrome / Edge）中双击 `index.html` 打开游戏。
2. 点击主菜单上的「打开关卡文件夹」，在弹出的系统选择器里选中存放 `.txt` 关卡的文件夹（例如项目自带的 `levels/` 目录）。
3. 浏览器会请求读写该文件夹的授权；同意后，文件夹里所有 `.txt` 关卡会自动出现在「本地文件夹」列表中。
4. 每个本地关卡都可以「开始」游玩或「编辑」。

## 如何修改本地关卡并保存

1. 在主菜单「本地文件夹」列表中，点击某个关卡的「编辑」，进入编辑器。
2. 修改完成后点击「保存」（或按 `Ctrl+S`）：
   - 正在编辑本地文件时，**直接覆盖写回原 `.txt` 文件**；
   - 编辑内置关卡或新建关卡时，保存到 localStorage（「我的关卡」列表）。
3. 「另存为本地文件…」会询问文件名，然后在已授权的文件夹里新建一个 `.txt`。
4. 编辑器里的「打开本地关卡…」可以从已授权文件夹中重新选择关卡载入。

## 浏览器兼容性说明

- **Chrome / Edge（推荐）**：支持 File System Access API，可以实时读取本地关卡文件夹，并把修改直接保存回本地文件。
- **Firefox / Safari**：不支持 `showDirectoryPicker`，自动降级：
  - 「打开关卡文件夹」变为只读模式（通过目录选择框加载，不写回）；
  - 编辑器里的「保存」变为「导出为 TXT 下载」，通过浏览器下载保存；
  - 页面会显示黄色小提示说明当前处于降级模式。
- 首次授权后，浏览器会把文件夹句柄存入 IndexedDB；下次打开页面时，如果授权仍然有效会自动恢复，无需重新选择。若授权已失效，主菜单会出现「恢复上次的关卡文件夹」按钮，点击后重新授权即可。

## 技术说明

- 零依赖、零构建，纯原生 HTML/CSS/JS。
- 不使用 ES Modules，不使用 `fetch()`，可在 `file://` 协议下直接运行。
- 所有代码挂载在全局命名空间 `window.PPZ` 下，每个文件为 IIFE。
- 内置关卡内联在 `js/levels/builtin.js` 中（该文件由 `scripts/build-levels.js` 从 `levels/*.txt` 自动生成）。

## 关卡开发

- 内置关卡源文件在 `levels/*.txt`，文件名排序决定显示顺序（`NN-<slug>.txt`，`NN` 为两位数字）。
- `js/levels/builtin.js` 是自动生成的，**不要手动编辑**。
- 修改关卡后运行 `npm run build:levels`（或常驻 `npm run watch:levels`）。
- 新增关卡流程：在 `levels/` 下新建 `NN-xxx.txt` → 写内容 → 编译 → 刷新浏览器。
- 提示：`js/levels/builtin.js` **要提交到 git**（因为 GitHub Pages 上不跑脚本）。
